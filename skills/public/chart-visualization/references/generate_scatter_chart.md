# generate_scatter_chart — Scatter Plot

## Overview
Plots relationship and correlation between two continuous variables across distinct observations.

## Input Fields
### Required
- data: array<object>, items with x (number) and y (number).

### Optional
- size: string, field driving bubble point diameter.
- color: string, field driving categorical coloring.
- 	heme: string, default default.
- 	itle: string, scatter title.

## Usage Recommendations
Add trendlines or clustering indicators when analyzing statistical correlations.

## Output
- Returns scatter plot image URL and spec in _meta.spec.
