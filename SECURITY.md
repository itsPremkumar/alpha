# Security Policy

## Supported Versions

This repository is maintained independently. Upstream release and branch
support policies do not establish support for this project. A supported-version
policy has not yet been published by the maintainer.

## Reporting a Vulnerability

Do not publish vulnerability details, credentials, or exploit instructions in
public issues. Use the private reporting option on
https://github.com/itsPremkumar/agent-workspace-desktop/security if it is available.
If private reporting is unavailable, ask the project maintainer to establish a
private reporting channel without disclosing vulnerability details publicly.
A dedicated security contact has not yet been published.
