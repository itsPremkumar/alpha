# Roadmap

Alpha's development roadmap organized by quarter.

## Q4 2026 (Current)

### ✅ Completed
- [x] Slash command palette with family expansion
- [x] Advanced @ bot tagging in Messages
- [x] Server-side mention preview API
- [x] CONTRIBUTORS.md with AI agent recognition
- [x] Docusaurus documentation site
- [x] SEO/GEO/AEO optimization (llms.txt, sitemap.xml, structured data)

### 🔄 In Progress
- [ ] Arena tool profiles and tournaments
- [ ] Enhanced workflow verification
- [ ] Improved memory consolidation
- [ ] Frontend performance optimization

### 📋 Planned
- [ ] Mobile-responsive UI improvements

- [ ] **Multi-modal agents** - Vision, audio, document processing

- [ ] **Automated testing** - AI-generated test suites
