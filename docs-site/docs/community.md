# Community

Join the Alpha community to connect with other users, get help, and contribute.

## Communication Channels

| Channel | Purpose | Link |
|---------|---------|------|
| **Discord** | Real-time chat, support, announcements | [discord.gg/alpha](https://discord.gg/alpha) |
| **GitHub Discussions** | Design discussions, RFCs, Q&A | [github.com/itsPremkumar/alpha/discussions](https://github.com/itsPremkumar/alpha/discussions) |
| **GitHub Issues** | Bug reports, feature requests | [github.com/itsPremkumar/alpha/issues](https://github.com/itsPremkumar/alpha/issues) |
| **Twitter** | Announcements, updates | [@alpha_ai](https://twitter.com/alpha_ai) |
| **Blog** | Deep dives, tutorials | [blog.itsPremkumar.com/alpha](https://blog.itsPremkumar.com/alpha) |

## Getting Help

### Before Asking

1. Check the [documentation](/)
2. Search [existing issues](https://github.com/itsPremkumar/alpha/issues)
3. Search [Discord](https://discord.gg/alpha) history

### Asking Questions

- Use GitHub Discussions for design questions
- Use GitHub Issues for bugs
- Use Discord for real-time help

### Bug Reports

Use the [bug report template](https://github.com/itsPremkumar/alpha/issues/new?template=bug_report.md)

### Feature Requests

Use the [feature request template](https://github.com/itsPremkumar/alpha/issues/new?template=feature_request.md)

## Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for detailed guidelines.

### Ways to Contribute

- **Code**: Bug fixes, features, refactoring
- **Documentation**: Fixes, tutorials, translations
- **Testing**: Bug reports, test cases
- **Community**: Answer questions, review PRs
- **Design**: UI/UX, diagrams, illustrations

### Recognition

All contributors are recognized in:
- [CONTRIBUTORS.md](../CONTRIBUTORS.md)
- GitHub Contributors graph
- Release notes
