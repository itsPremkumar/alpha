## How Contributors Are Recognized

Alpha recognizes contributors in multiple ways:

1. **GitHub Contributors Graph** — Automatic via commit history (see [GitHub Contributors](https://github.com/itsPremkumar/alpha/graphs/contributors))
2. **Commit Co-authorship** — AI agent contributions use `Co-Authored-By` trailers
3. **This File** — Explicit recognition for significant human, AI, and framework contributions

## Adding Yourself

If you've contributed to Alpha and would like to be listed here, please open a PR adding your name to this file. We welcome:

- Code contributions (features, fixes, refactors)
- Documentation improvements
- Bug reports and triage
- Testing and QA
- Infrastructure/tooling improvements
- AI-assisted contributions (disclosed per our [PR template](.github/pull_request_template.md))
